# 剪辑规则（通用版）

适用于知识类播客（对谈、访谈、单人讲述）。这些规则最初来自一档法律对谈节目多期「AI 第一稿 vs 人工定稿」的逐条对比复盘。每一期定稿后，把人工额外删掉的和恢复的地方逐条分类，能跨期成立的才写进这里。单期的原话例子和细节数字不放在本仓库。

> 规则状态：**已验证** = 多期定稿复核成立；**样本** = 单期观察，待跨期验证。

## 总原则（已验证）

1. **表达可以精简，观点和案例必须保留。** 不要因为说得乱、卡壳，就把有观点或案例的整段删掉。
2. **取舍单位是句子，不是段落。** 有观点或案例的段落，保留核心论断和案例事实，删段内的引子、绕弯、重复和半句；段内一般留 55–85%。
3. **长度相近不代表删对了。** 复盘要看内容重合度：AI 稿和定稿时长可能几乎一样，但 AI 删掉的是观点、留下的是口水。
4. 离长度目标还差时，先把整段删除候选列给制作人选，不自作主张删观点。
5. 文稿里标红的原话一个字不删（按字保护，标红区间里的口水词照样可删）。

## 长度基准

| 版本 | 占原始时长 | 主要靠 |
|---|---|---|
| 粗剪 | 60–70% | A 层 + C 层；B 层只删下表几类 |
| 精剪定稿 | 55–65% | 在粗剪上再做大量逐字精简 |
| 音频平台版 | 约 50% | 在粗剪基础上继续压缩，主要靠 B′ 层（样本） |
| 不设长度目标的闲聊特辑 | 80–90% | 主要靠 C 层（样本） |

## 分层

### A 录制废料（直接删）
开场前调试、“开始”、打板、“停一下”、重录的前一遍、中途休息闲聊、讨论怎么录、当场放弃的话题、结尾后的空档。

### B 整段删（只限这些类别）
1. 纯玩笑、调侃、内部梗，不带观点。包袱抖完后的补刀、接梗都删，只留推进内容的那一句。
2. 口误来回、名词纠正来回。
3. 重复的回指、对没讲内容的交代、重复的感谢。
4. 主持人元话语和复述：问题前的长铺垫、对回答的复述总结。
5. 预告、闲评、即兴估算（即使在保留的段落里也删）。
6. **推测和假设，即使带观点**：案情没披露时“如果……那就……”式的推算。
7. 专业内容外的周边闲谈和感叹。
8. 开场极简：上期反馈和留言压成一句，直接进第一问。

段内精简：
- **案例**：保留案情、定性、关键证据、结果；删回忆名字的停顿、绕弯的引子、细节重复。
- **论述**：保留每一点的论点和一句支撑；删开讲前的招呼、引子、同一点的第二遍。
- **来回争论**：保留双方各一次的核心论点和结论；删重复轮次和逐项罗列。
- **问答**：问题和答案都要完整，不能删到只剩问题和“对了”。如果回答自己能说清楚，提问可以删。
- **保护**：新案例、新话题的引入句，后文指代依赖的内容。

### B′ 分句与短段精简（0.6–15 秒；平台版主力，样本）
- **同一个点只讲一遍**：第二种说法、第二组数字、第二个类比、讲完之后的总结回指。
- 评论、感叹、推测、评价，即使有信息量也删；保留事实和结论。
- 元话语和铺垫：“先说一下”“我想表达的是”。
- 案例细节压到能推进叙事的程度；补充数字、旁支例子删。
- 编号、出处（法条号、论文、年份等）只在第一次出现或承担论证时保留。
- 和本期主线关系远的专业展开（相邻概念、背景理论、学理区分）：**先列为候选，由制作人确认**。
- 平台精简可以推翻粗剪阶段的保留决定。

### C 句内逐字精简（全片默认）
人工定稿里的逐字删除约为每原始分钟 6 秒，第一稿就要做到这个覆盖：
- <0.6s：孤立的呃、嗯、啊；句首“然后、就是、那个、对吧”。
- 0.6–1.5s：起句重复（“我我”“那那”）。
- 1.5–5s：说一半推倒重来的半句、重新解释的引子。
- 他人不承担语义的应声：“嗯嗯”“对对对”。
- 停顿 ≥0.7s 缩到 0.4s。
- 明确的半句重来和重复直接删，不留给人决定。
- 转写时间戳不准时，逐处核对，只撤回失败的剪点，不要整层放弃。

## 交付前必查
1. **标红双向核对**：先把每段标红原文对到录音上，再确认它在成片里还在。
2. **通读每个接口**：被切掉一半的词、残留的单字、主语或指代悬空、问答缺答案。

## 人机协作流程
- AI 出方案（EDL）→ 制作人确认 → AI 执行已确认项 → 制作人在剪辑软件里逐字精修 → AI 读定稿做复盘、更新规则。
- 按时间码从后往前执行，减少删除造成的时间码位移。
- 字幕用于定位语义，原音用于确定剪点，画面用于复核；不能只凭字幕猜剪点。
- 工程修改和导出分开；导出只在试听确认后做。
- 复盘时单期结论先记为「样本」，跨期成立才升为默认规则。

## 包装与声音
- 定稿音频目标约 -18 LUFS，响度范围（LRA）约 5。
- 片头音乐垫在开场下，最后一位主持人自我介绍结束时退出；片尾音乐从结语起进，铺到最后一处人声结束。
- 有广告时插在第一个问题问完、回答开始前，前后各约 2 秒转场音效。
- 声音处理先做 10–20 秒样段 A/B 试听，确认后再全片应用。
