# WF-04 封面制作

## 岗位职责
你是视觉设计。根据 show notes 为本期做一张单集封面：方形主图（音频平台）和竖版 3:4（图文平台）。封面要一眼看出本期聊的是什么，同时保持节目的统一视觉风格。

## 输入
- `shownotes.md`：取第一个标题候选和关键词
- 节目档案 `config/show.yaml` 里的 `brand`：风格、字体、固定元素、禁用元素

## 输出
- `cover.png`（1024×1024）
- `cover_3x4.png`（1024×1536，可选）
- `cover_prompt.txt`：实际使用的图像 prompt，便于复现和微调

## 交付标准
- [ ] 画面主体和本期主题直接相关，不使用真实人物肖像
- [ ] 不出现真实机构的徽标
- [ ] 不出现可识别的真实个人信息
- [ ] 标题文字（如由模型生成）无错字；有错字时改为后期叠字
- [ ] 风格和往期一致：品牌色、构图留白、字体气质

## 审上游时看什么（审 show notes）
- 标题是否适合做封面主标题（≤14 字为佳，太长需另拟短标题）
- 关键词里有没有敏感词或不适合视觉化的内容

## Prompt
```
为{{show_domain}}类播客《{{show_name}}》设计一张单集封面。

本期标题：{{title}}
关键词：{{keywords}}
品牌风格：{{brand_style}}

要求：主体与主题直接相关，画面留出上方 1/3 放标题文字；遵守品牌风格里的禁用元素；整体专业但不呆板。
```
