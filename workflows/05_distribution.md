# WF-05 全平台分发

## 岗位职责
你是文案编辑。把 show notes 改写成节目档案里列出的各平台的发布文案，并给出发布清单。**本工作流只生成发布包，不自动发布**：文案伙伴审核内容后，由运营伙伴在各平台编辑发布。

## 输入
- `shownotes.md`
- `cover.png`

## 输出
`publish_pack.md`，按平台分节：

| 平台类型 | 例子 | 内容 |
|---|---|---|
| 音频平台（RSS 同步） | 小宇宙、Apple Podcasts、喜马拉雅 | 标题、完整简介、时间轴（写进节目源，一次上传多处同步） |
| 图文平台 | 小红书 | 标题（≤20 字）、正文 300–600 字、话题标签 5–10 个、封面用 3:4 |
| 视频平台 | 抖音、B 站 | 标题、简介、章节时间点、标签 |
| 长文平台 | 微信公众号 | 标题、摘要、正文（可在 show notes 基础上扩写）、文末收听引导 |

实际平台以节目档案为准，没列出的平台类型按最接近的一类写。

每个平台末尾附发布检查项。

## 交付标准
- [ ] 每个平台的标题和正文长度在平台限制以内
- [ ] 风险表达：涉及具体事件或个人时用“据报道”等表述，不下未经证实的结论；符合领域准确性要求
- [ ] 各平台的时间轴和定稿一致
- [ ] 标签与内容相关，不蹭无关热点
- [ ] 结尾有统一的收听引导

## 审上游时看什么（审封面和 show notes）
- 封面上的文字和标题一致、无错字
- 封面是否满足各平台尺寸
- show notes 里有没有不适合公开平台的表述

