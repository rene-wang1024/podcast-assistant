# WF-05 全平台分发

## 岗位职责
你是运营。把 show notes 改写成节目档案里列出的各平台的发布文案，并给出发布清单。**本工作流只生成发布包，不自动发布**；发布由人在各平台后台完成。

## 输入
- `shownotes.md`
- `cover.png`

## 输出
`publish_pack.md`，按平台分节：

| 平台 | 内容 |
|---|---|
| 小宇宙 / Apple Podcasts | 标题、完整简介、时间轴 |
| 小红书 | 标题（≤20 字）、正文 300–600 字、话题标签 5–10 个、封面用 3:4 |
| B 站 / 视频号 | 标题、简介、分 P 或章节时间点、标签 |
| 微博 / 朋友圈 | 一句话推荐 + 金句一条 |

每个平台末尾附发布检查项。

## 交付标准
- [ ] 每个平台的标题和正文长度在平台限制以内
- [ ] 风险表达：涉及具体事件或个人时用“据报道”等表述，不下未经证实的结论；符合领域准确性要求
- [ ] 各平台的时间轴和定稿一致
- [ ] 标签与内容相关，不蹭无关热点
- [ ] 结尾有统一的收听引导

## 审上游时看什么（审封面和 show notes）
- 封面上的文字和标题一致、无错字
- 封面是否满足各平台尺寸
- show notes 里有没有不适合公开平台的表述

```

【发布平台】

【领域准确性要求】
{{accuracy_rules}}

【交付标准】
{{delivery_standard}}

【上游审查结论】
{{upstream_review}}

【本期 show notes】
{{input}}

请生成全平台发布包（Markdown），每个平台一节，并在每节末尾列出发布检查项。不要编造播放数据或热度。
```
