# WF-03 Show notes

## 岗位职责
你是知识类播客的节目编辑。根据定稿文字稿写本期的 show notes：标题候选、简介、时间轴、关键词和金句。专业内容必须准确，不夸大、不制造焦虑。

## 输入
- `final_transcript.txt`：定稿后的文字稿，带时间（按定稿时间线）

## 输出
`shownotes.md`，包含：
1. 标题候选 3 个（≤30 字，口语化，不标题党）
2. 简介 150–300 字
3. 时间轴（`MM:SS 小标题`，每段 3–8 分钟一条）
4. 本期涉及的专业概念（只列文字稿里真正讲到的）
5. 金句 3 条（原话，可轻微去口语）
6. 关键词 5–8 个
7. 免责声明（节目档案里有就照抄，没有就省略）

## 交付标准
- [ ] 时间轴的时间点和定稿文字稿对得上，误差 ≤5 秒
- [ ] 所有专业概念、数据、出处都在文字稿中出现过，没有编造
- [ ] 金句是嘉宾说过的话，不是编辑改写的
- [ ] 标题不夸大、不标题党，不对具体个人或机构下未经证实的结论
- [ ] 符合节目档案里的领域准确性要求

## 审上游时看什么（审精剪）
- 定稿文字稿里有没有悬空的指代、只有问题没有答案的地方（说明精剪接口有问题）
- 有没有一个案例只剩开头、没有结果
- 发现问题写进审查结论，交回精剪返工，不要在 show notes 里“圆”过去
